# Лакей — ТЗ: меню и пользовательские сценарии

Текстовая версия графического ТЗ (`лакей.xlsx`). Схема читается по стрелкам 👉 / 👇 / 👈 / 👆: каждый блок — один экран бота.

## Обозначения

| Элемент схемы | Что значит |
|---|---|
| Жёлтая ячейка | Inline-кнопка |
| Ячейка цвета `(つ✧ω✧)つ` | Кнопка Reply Keyboard |
| Ячейка цвета `✍️` | Реакция бота на сообщение пользователя |
| Голубая ячейка со ссылкой | URL-кнопка / ссылка |
| Рамка без заливки | Сообщение бота |
| `Назад` | Возврат на предыдущий экран |

---

## 5. Сценарий «В гости»

```
Меню → В гости → Город? → Коммуна? → Когда? → Текст → Итоговое сообщение
```

### 5.1. Город?

Inline-кнопки (один ряд): `Москва` · `Питер` · `Владик`

### 5.2. Коммуна?

Кнопки идут одним столбцом, список зависит от города.

| Москва | Питер | Владик |
|---|---|---|
| Бестиарий | Зиккурат | Пассад |
| Могильный Платон | CORPUS BOREALIS | Назад |
| MAGNUM CORPUS | Пинатксат | |
| Пу-пу-пу | Андердоги | |
| Гицхаус_П | Всё Просто | |
| Гицхаус_К | Назад | |
| Назад | | |

### 5.3. Когда?

Inline-кнопки (один ряд): `Сегодня` · `Завтра` · `Послезавтра` · `Назад`

### 5.4. Ввод текста

Сообщение: «Напиши прилагаемое послание». Кнопка: `Назад`.

Пользователь пишет текст, например `привет, можно прийти к 17:30?`. Бот ставит на сообщение пользователя реакцию ✍️ как при сообщении

### 5.5. Итоговое сообщение

```
@thetrtk хочет прийти сегодня в гости
↳ привет, можно прийти к 17:30?
```

Шаблон: `{@username} хочет прийти {когда} в гости` и на новой строке `↳ {текст}`.

## 6. Сценарий «Вписаться»

```
Меню → Вписаться → Город? → Коммуна? → Когда? → На сколько дней → Текст → Итоговое сообщение
```

Экраны **Город?**, **Коммуна?** и **Когда?** — те же, что в [сценарии «В гости»](#5-сценарий-в-гости) (пп. 5.1–5.3), но на экране **Когда?** добавлена кнопка `В другой день` (вторым рядом, рядом с `Назад`). Только у «Вписаться»; у «В гости» её нет.

### 6.0. В другой день

Если нажато `В другой день`, перед шагом «На сколько дней» добавляется экран: «Напиши, в какой день (напр. 15 ноября)». Кнопка: `Назад` (возврат на «Когда?»). Пользователь пишет дату текстом (до 40 символов), и она подставляется в итоговое сообщение вместо «сегодня/завтра/послезавтра»:

```
@thetrtk хочет вписаться 15 ноября на 4 дня
↳ привет, можно вписаться?
```

### 6.1. На сколько дней

Сообщение: «Напиши на сколько дней (напр. 4)». Кнопка: `Назад`.

### 6.2. Ввод текста

Сообщение: «Напиши прилагаемое послание». Кнопка: `Назад`.

Пользователь пишет текст, например `привет, можно вписаться?`. Бот ставит реакцию ✍️, затем 🌟.

### 6.3. Итоговое сообщение

```
@thetrtk хочет вписаться сегодня на 4 дней
↳ привет, можно вписаться?
```

Шаблон: `{@username} хочет вписаться {когда} на {N} дней` и на новой строке `↳ {текст}`.

## Открытые вопросы по исходной схеме

- **Знамя** есть в списке коммун, но отсутствует в кнопках «Коммуна?» для Питера (в обоих сценариях).
- **Гицхаус_П** и **Гицхаус_К** ведут на одну и ту же ссылку (`t.me/GITSAREON`).
- В примере итогового сообщения «на 4 дней» — нужно склонение (1 день / 2–4 дня / 5+ дней).
- Значение 🌟 на схеме не подписано. Здесь оно понято как отметка успешной отправки.
- Стрелок для `Назад` на схеме нет. Здесь везде понято как возврат на предыдущий шаг.
- Не указано, что происходит после отправки итогового сообщения (возврат в меню или нет).

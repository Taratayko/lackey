## Ожидаемое поведение

Поведение бота должно остаться прежним:

- `/ban` ответом на сообщение банит пользователя в текущем чате;
- `бан` текстом ответом на сообщение работает так же;
- `/megaban` и `мегабан` банят пользователя во всех зарегистрированных чатах;
- `/unban @username` и `разбан @username` разбанивают пользователя;
- `/banlist` показывает чёрный список;
- при бане удаляются сохранённые сообщения пользователя из текущего чата;
- при мегабане удаляются сохранённые сообщения пользователя из каждого зарегистрированного чата.

## Как проверять после наката

1. Запустить бота через `start_bot.bat`.
2. В тестовой беседе отправить обычное сообщение от тестового пользователя.
3. Администратором ответить на него командой `/ban`.
4. Проверить, что пользователь забанен, а сохранённые сообщения удалены.
5. Проверить текстовый вариант `бан` ответом на сообщение.
6. Проверить `/banlist`.
7. Проверить `/unban @username`.
8. Проверить текстовый вариант `разбан @username`.
9. Аккуратно проверить `/megaban` / `мегабан` только на тестовом пользователе и тестовых чатах.
10. Проверить `/help` в беседе: админ должен видеть блок админских команд.
11. Проверить, что обычная ретрансляция текста, media relay и reply-цепочки не сломались.
12. Запустить сборку:

```bash
bash build.sh
```

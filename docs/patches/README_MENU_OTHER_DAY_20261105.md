# «Вписаться» → «Когда?» → «В другой день» (05.11.2026)

Надстройка над патчем меню от 04.11.2026 (`README_MENU_20261104.md`). Ставится поверх него.

## Что добавлено

- На экране «Когда?» сценария **«Вписаться»** появилась кнопка `В другой день`:
  ```
  [Сегодня] [Завтра] [Послезавтра]
  [В другой день] [Назад]
  ```
  У сценария **«В гости»** экран прежний (3 дня + `Назад`), кнопки там нет.
- По нажатию открывается новый шаг **«Напиши, в какой день (напр. 15 ноября)»** (кнопка `Назад`).
  Пользователь пишет дату текстом, затем идёт обычное «На сколько дней» → «Текст».
- Итог в коммуне:
  ```
  @user хочет вписаться 15 ноября на 4 дня
  ↳ текст
  ```
- `Назад`: «Текст» → «Дни» → «Дата» → «Когда?». Если на «Когда?» передумали и выбрали «Сегодня»,
  введённая дата сбрасывается, шага «Дата» больше нет.

## Решения по умолчанию

| Вопрос | Решение | Где менять |
|---|---|---|
| Формат даты | Свободный текст, пробелы/переводы строк схлопываются, 1…40 символов, без разбора | `domain/menu_flow.parse_date`, `MAX_DATE_LEN` |
| Экранирование | Введённая дата экранируется в HTML заявки | `presentation/menu_texts.format_stay_request` |
| Подпись кнопки | «В другой день» | `domain/menu_flow.BTN_OTHER_DAY` |
| Callback | `lk:when:other` (подделка в «В гости» отклоняется как «Меню устарело») | `MenuFlowService.choose_when` |

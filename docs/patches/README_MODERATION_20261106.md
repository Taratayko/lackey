# Модерация: мут и бан админами (06.11.2026)

## Что сделано

- Новые команды в беседах: `/mute`, `/unmute`, `/ban`, `/unban`, `/banlist`
  и текстовые формы «мут», «размут», «бан», «разбан» (ответом на сообщение).
- `/mute [срок] [причина]`: срок словами — `30 минут`, `2 часа`, `1 день`, `30 дней`,
  `1 неделя` — или коротко (`30м`, `2ч`, `1д`, `1н`, `30дней`), либо `навсегда`;
  без срока — 1 час (`DEFAULT_MUTE`). Дольше 366 суток Telegram всё равно считает мут
  бессрочным. В ответах бота срок пишется словами («2 часа», «30 дней»).
- `/mutelist` — замученные в чате с оставшимся временем; `/banlist` — чёрный список.
- `/ban` удаляет сообщения нарушителя: бот логирует id сообщений участников групп
  (`MessageLogMiddleware` на корневом роутере → коллекция `user_messages`, TTL 7 суток,
  `MESSAGE_LOG_TTL_DAYS` в `adapters/mongo/message_log.py`). Удаляется всё, что бот видел
  за этот срок, и сообщение, на которое ответили командой. В ответе: «Удалено сообщений: N»
  и число неудач (обычно — у бота нет права удалять сообщения).
- `/help` в беседе: тем, кто может банить и мутить, показывается `GROUP_HELP_ADMIN`
  с командами модерации; остальным — обычный `GROUP_HELP`.

## Устройство

- Источник истины — Telegram (`ban_chat_member`, `restrict_chat_member`).
- Журнал `moderation_actions` в Mongo (одна запись на `chat_id + user_id + kind`)
  нужен только для `/unban @ник`, `/unmute @ник` и `/banlist`. Сбой журнала не
  ломает уже выполненный бан/мут. Истёкшие муты из выборок исключаются.
- `ChannelPort`: `can_restrict_members`, `mute_user`, `unmute_user`
  (VK/Web — заглушки `NotImplementedError`).
- Права: админ с `can_restrict_members`, создатель чата, `settings.ADMIN_ID`,
  анонимный админ (отправка от имени группы).
- Нельзя применить к админу, к самому себе и к боту. Ответ на сообщение
  канала/анонимного админа отклоняется.
- Размут возвращает права чата по умолчанию (`getChat().permissions`), а не «все права».
- Слова-триггеры не срабатывают на сообщениях с «!» (формат ретрансляции
  «Название! текст»), а у не-админов пропускают сообщение дальше по роутерам.

## Требования к боту

Бот должен быть админом чата с правами «Блокировка пользователей» и «Удаление сообщений».
Мут работает только в супергруппах (ограничение Telegram).

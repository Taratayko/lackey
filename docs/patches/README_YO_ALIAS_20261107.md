# е/ё в названиях коммун + пересылка «как написано» (07.11.2026)

## Что сделано

- К коммуне можно обращаться с «е» или «ё» как угодно: `Всё просто!` и `Все просто!`
  — одна и та же коммуна, отдельный алиас заводить не нужно. Регистр, как и раньше, не важен.
  Работает для названия (`slug`) и для всех алиасов, в беседах и в ЛС, для текста, медиа,
  альбомов и пересылки ответом (`Название!`).
- `/addalias` не создаёт «лишний» алиас, который отличается от названия коммуны или от уже
  существующего алиаса только е/ё. `/removealias` тоже не различает е/ё.
- Бот пересылает сообщение вместе с названием/алиасом коммуны в том виде, как написал отправитель:
  ```
  from Зиккурат от @user
  ↳ Всё просто! Хай!

  from Зиккурат от @user
  ↳ Простые! Хай!
  ```
  Для медиа, альбомов и пересылки ответом то же самое: в подписи/комментарии остаётся
  `Название! текст` (или просто `Название!`).

## Устройство

- `domain/names.py` (новый) — `fold_name`, `same_name`, `yo_insensitive_regex`.
- `database.get_chat_by_name`: сначала точный поиск (индекс), затем запасной по regex с `[её]`.
  Если у разных коммун вдруг есть и «все», и «всё», выигрывает написанное буква в букву.
  Миграция данных не нужна: старые алиасы с «ё» находятся по запросу с «е» и наоборот.
- `handlers/common.text_as_written` и `resolve_chat_and_text` теперь отдают исходный текст целиком.

## Где отключить «как написано», если понадобится

- Текст: `adapters/telegram/handlers/common.py` → `resolve_chat_and_text` (вернуть `resolved` как есть).
- Медиа-подписи только с именем: `group_media.py`, `albums.py`, `dm.py` (строки с `text_as_written`).
- Пересылка ответом: `forward_reply.py` (`text=intent.comment`).

## Проверка вручную

1. В беседе: `Все просто! Хай!` при коммуне «Всё просто» — сообщение доходит, в коммуне `↳ Все просто! Хай!`.
2. `Простые! Хай!` по алиасу — в коммуне `↳ Простые! Хай!`.
3. `/addalias все просто` в беседе «Всё просто» → «Такой алиас уже есть».
4. Фото с подписью `Всё просто!`, ответ `Всё просто!` на чужое сообщение, то же из ЛС.

# Меню после отправленного послания (07.11.2026)

После успешной отправки заявки «В гости» / «Вписаться» бот присылает новым сообщением
главное меню (`🪁Меню:` с кнопками), чтобы не нажимать `(つ✧ω✧)つ` заново.

- Меню не показывается, если доставка не удалась (сценарий остаётся, можно отправить ещё раз).
- При частичной доставке сначала приходит сообщение об ошибке, затем меню.
- Сбой показа меню логируется и не превращает доставленную заявку в «не доставлено».

Файлы: `adapters/telegram/handlers/menu.py` (`send_main_menu`, вызов из `deliver_request`),
`tests/test_menu_flow.py`, новый `docs/patches/README_MENU_AFTER_SEND_20261107.md`.
